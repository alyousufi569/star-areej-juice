# STAR AREEJ JUICE — إضافة المنيو

## محتويات الحزمة
- `seed_menu.sql`: يضيف قائمة بداية مقترحة إلى جدول `public.products`.
- الأسعار موحدة: صغير 5 ريال، وسط 8 ريال، كبير 10 ريال.
- السعرات لا تُخمن؛ ستظهر فارغة إلى أن تدخل القيم الصحيحة من لوحة الإدارة.

## طريقة الإضافة
1. افتح مشروع Supabase المرتبط بموقعك.
2. افتح SQL Editor ثم New query.
3. افتح `seed_menu.sql` وانسخ محتواه إلى الاستعلام.
4. نفّذ الاستعلام مرة واحدة. الاستعلام لا يحذف المنتجات الموجودة ويتجاوز الصنف إذا كان الاسم والقسم موجودين مسبقاً.
5. افتح `https://alyousufi569.github.io/star-areej-juice/admin.html` وسجّل دخول المدير.
6. من «المنتجات والسعرات» تستطيع تعديل الاسم والوصف والقسم والأسعار والسعرات والصورة، أو إخفاء الصنف أو حذفه.
7. افتح واجهة المتجر وتأكد من ظهور الأصناف.

## التحكم الإداري الموجود حالياً
- إضافة وتعديل وحذف وإخفاء المنتجات.
- تعديل أسعار الأحجام الثلاثة.
- إدخال السعرات لكل حجم.
- رفع صورة المنتج من الجهاز إلى مساحة صور Supabase.
- إدارة العروض والطلبات وتغيير حالة الطلب.

## ملاحظات مهمة
- هذه قائمة بداية أصلية مقترحة بأصناف شائعة، وليست نسخاً حرفياً من متجر آخر.
- الصور روابط توضيحية خارجية. الأفضل استبدالها بصور منتجات المحل من لوحة الإدارة قبل الإعلان.
- لا تُدخل السعرات إلا بناءً على وصفة المنتج وكمياته أو بيانات غذائية موثوقة.
- لم يتم تعديل ملفات GitHub مباشرة لأن اتصال GitHub الحالي لا يملك صلاحية الكتابة إلى المستودع. يمكنك إضافة ملف SQL يدوياً أو منح اتصال GitHub صلاحية الكتابة.
